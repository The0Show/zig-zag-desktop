## Installation
You can find the latest release [here](https://github.com/The0Show/zig-zag-desktop/releases/latest).

## Building
1. Clone the code via your favorite method.
> [!TIP]
> I'm using [`jj`](https://www.jj-vcs.dev/latest/) but Git should also work just fine.
2. Use [`pnpm`](https://pnpm.io) to install dependencies (`pnpm i`).
3. Run the app using `pnpm run start`.
